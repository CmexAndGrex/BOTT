### 2. ✅ ЗАЩИТА ОТ ОБНУЛЕНИЯ RS-RED (HIGH-WATER MARK)

**Проблема:** В воскресенье 23:55–00:00 rs-red.com сбрасывает онлайн в 0. Если синхронизация происходит после сброса, часы за неделю теряются.

**Решение:**
- При КАЖДОЙ синхронизации (`syncRoster()`) автоматически делается upsert в `weekly_stats` за текущую неделю
- Используется `GREATEST(existing_hours, new_hours)` — сохраняется максимум
- При закрытии недели (`runWeeklyRecord()`) берутся часы из сохранённого high-water mark, а не из `member.hours`

**Файлы:**
- ✅ `/src/lib/tasks.ts`:
  - `syncRoster()` — добавлен upsert с `GREATEST()` при каждой синхронизации
  - `runWeeklyRecord()` — изменён на чтение из `weekly_stats` вместо прямого `fighter.hours`

### 4. ✅ ИСПРАВЛЕНИЕ FRONTEND (DATE-BASED LOOKUP)

**Проблема:** Фронтенд брал данные позиционно из массива `stats[0]`, `stats[1]`, `stats[2]`.

**Решение:**
- API теперь возвращает:
  - `weekStats: { [weekStart]: { hours, vacation } | null }` — объект по ключу даты
  - `weekKeys: { week3, week2, week1, week0 }` — точные даты для заголовков колонок
- Фронтенд делает lookup строго по `weekStats[weekKeys.week3]`, а не по индексу
- Если записи нет — отображается прочерк `—`
- Заголовки колонок формируются через `formatWeekRange(weekKeys.weekN)`

**Файлы:**
- ✅ `/src/app/control/page.tsx` — переработан на date-based lookup
- ✅ `/src/app/api/control/route.ts` — возвращает `weekStats` и `weekKeys`

## 📝 ТЕХНИЧЕСКИЕ ДЕТАЛИ

### Формат week_start:
- Тип: `text` (а не `date`) для совместимости с JSON API
- Формат: `YYYY-MM-DD` (ISO 8601)
- Примеры: `"2026-10-05"`, `"2026-10-12"`, `"2026-10-19"`
- Всегда понедельник недели по МСК

### Логика high-water mark:
```sql
INSERT INTO weekly_stats (member_id, week_start, hours, vacation)
VALUES (123, '2026-10-19', 15.5, false)
ON CONFLICT (member_id, week_start) DO UPDATE
SET hours = GREATEST(weekly_stats.hours, EXCLUDED.hours);
```

### Нормализация имён (seed):
```typescript
normalizePlayerName("Акулова Д.В..") === "акулова д в"
normalizePlayerName("Мутагенов И. С.") === "мутагенов и с"
```
