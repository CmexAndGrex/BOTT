# Полный гайд: Google-формы → Discord → БД и Google Таблица

Всё начинается с одной Google-формы. Боец отправляет ответ → заявка попадает
в канал Discord → модератор ставит **🟢 / ✅ / :ATK:** (одобрить) или **❌**
(отказать) → бот выполняет действие и пишет итог в ветку под заявкой.

| Тип заявки в форме | Что делает бот при 🟢 |
|---|---|
| **Добавить в ШДС** | вносит бойца в Google Таблицу (лист «Танковая рота» / «Артиллерийский дивизион», первая свободная «Вакант»-строка) и **автоматически выдаёт роли из данных формы**: направление (ТР/АД из «Подразделения») + звание + общие роли (корпус, категория «Звания», снимаются «Новобранец»/«Друг АТК») |
| **Отпуск** | ставит статус отпуска в БД панели (сайт) + выдаёт роль «Отпуск» в Discord + пишет бойцу в ЛС. За день до конца отпуска — автоматический пинг **в 12:00 МСК** |
| **Снять отпуск** | убирает статус в БД + снимает роль «Отпуск» |
| **Управление ролями** | выдаёт роли из списка «Роль (выдать)» и снимает из «Роль (снять)» — одним запросом |
| **Сдать экзамен** | находит бойца в ШДС, красит ячейку экзамена зелёным, пишет оценку (КМБТ — без оценки), экзаменатора и дату — в примечание к ячейке |
| **Уйти в запас** | строка бойца ЦЕЛИКОМ (со всеми заливками экзаменов) переносится на лист «Запас», в подразделении встаёт «Вакант»; роли снимаются, выдаётся роль «Запас» |
| **Вернуться из запаса** | строка с экзаменами возвращается в подразделение — в НИЖНЮЮ свободную строку блока прежней должности; роль «Запас» снимается, прежние роли восстанавливаются |

Доставка заявок из формы в Discord — двумя способами (можно оба сразу):

- **Вариант A — опрос таблицы (рекомендуется, работает даже локально без
  интернета).** Бот раз в минуту читает лист «Ответы на форму 1» и публикует
  новые строки. Настройка — один переключатель в панели.
- **Вариант B — вебхук через Apps Script.** Заявка улетает в Discord мгновенно
  в момент отправки формы.

## Часть 1. Создание Google-формы

1. Откройте [forms.google.com](https://forms.google.com) → «Пустая форма».
2. Название: **«Заявки АТК»**.
3. Создайте вопросы с такими заголовками (бот ищет по заголовкам, порядок не важен):

| # | Заголовок вопроса | Тип | Обязательный | Когда используется |
|---|---|---|---|---|
| 1 | **Имя пользователя** | Выпадающий список | ✅ | всегда (список бойцов из ШДС — см. п. 4.3) |
| 2 | **Discord ID** | Короткий ответ | — | для новичков; у действующих бойцов бот найдёт ID сам |
| 3 | **Тип заявки** | Выпадающий список | ✅ | всегда |
| 4 | **Подразделение** | Выпадающий список | ✅ | ШДС / запас / экзамен |
| 5 | **Звание** | Короткий ответ | — | ШДС |
| 6 | **Steam ID** | Короткий ответ | — | ШДС |
| 7 | **Роль (выдать)** | Выпадающий список / сетка | — | роли, добавление в ШДС |
| 8 | **Роль (снять)** | Выпадающий список | — | роли |
| 9 | **Экзамен** | Выпадающий список | — | экзамен |
| 10 | **Оценка** | Выпадающий список | — | экзамен (для КМБТ оставить пустой) |
| 11 | **Экзаменатор** | Короткий ответ | — | экзамен (Фамилия И.О.) |
| 12 | **Даты отпуска** | Короткий ответ | — | отпуск |
| 13 | **Причина** | Абзац | — | всегда |

4. Варианты **«Тип заявки»** (скопируйте как есть):

```
Добавить в ШДС
Управление ролями
Сдать экзамен
Отпуск
Снять отпуск
Уйти в запас
Вернуться из запаса
```

5. Варианты **«Подразделение»**:

```
Танковая рота
Артиллерийский дивизион
```

6. **«Роль (выдать)»** и **«Роль (снять)»** — названия ролей сервера
   (Настройки сервера → Роли). Для «Управления ролями» можно писать и
   составные звания («Капитан ТР», «Рядовой АД»).

   > ⚠️ В вопросе **«Звание»** (для «Добавить в ШДС») пишите чистые звания
   > БЕЗ суффикса: `Рядовой`, `Ефрейтор`, `Мл. Сержант`, `Сержант`,
   > `Ст. Сержант`, `Старшина`, `Прапорщик`, `Ст. Прапорщик`, `Лейтенант`,
   > `Ст. Лейтенант`, `Капитан`, `Майор`, `Подполковник`, `Полковник`.
   > Направление (ТР/АД) бот возьмёт сам из «Подразделения» и выдаст
   > направление + звание + общие роли автоматически.

7. **«Экзамен»** — названия экзаменов ТОЧНО как в шапке листа ШДС
   (строка с заголовками экзаменов) + «КМБТ».

8. **«Оценка»** — например: `Зачёт`, `Незачёт`, `Отлично`, `Хорошо`,
   `Удовлетворительно` (или ваша шкала). Для КМБТ боец оставляет пустой.

9. **«Даты отпуска»** — свободный текст: «с 10.08.2025 по 20.08.2025»,
   «20.08.2025» или просто «20.08» (год бот подставит сам).

> В описании формы подскажите бойцам: «Discord ID можно не заполнять —
> бот найдёт тебя по имени в ШДС. Новички — Discord ID обязателен
> (Настройки Discord → Расширенные → Режим разработчика → ПКМ по нику →
> Копировать ID)».

## Часть 2. Привязка формы к таблице ШДС

1. Форма → вкладка **«Ответы»** → зелёный значок таблицы →
   **«Существующая таблица»** → ваша таблица ШДС
   (`1FkC6pdThOnQ_chrKy90bIsM2xEr6qeazhN_OCsSO-s0`).
2. Google создаст лист **«Ответы на форму 1»** — запомните название.
3. Дайте сервисному аккаунту бота доступ **Редактор** к таблице:
   email вида `...@...iam.gserviceaccount.com` из JSON-паспорта
   (`gsheet_service_account` в панели) → «Поделиться» → Редактор.

## Часть 3. Вариант A — опрос таблицы (рекомендуется)

Скрипты не нужны. Панель → **Настройки**:

1. Секция **«Google-форма и запас»**:
   - **Опрос Google-формы** — включить;
   - **Лист с ответами формы** — `Ответы на форму 1`;
   - **ID роли «Запас»** — ID роли запаса;
   - **Название листа «Запас»** — `Запас` (создастся сам).
2. Секция **«Бот заявок и Google Таблица»**:
   - `shds_channel_id` — канал заявок ШДС (добавление, экзамены, запас);
   - `vacation_channel_id` — канал отпусков;
   - `roles_channel_id` — канал запросов ролей;
   - `moderator_role_id` — роль модератора (кто может одобрять);
   - `leave_role_id` — роль «Отпуск»;
   - `gsheet_spreadsheet_id` — ID таблицы ШДС из URL;
   - `gsheet_service_account` — JSON-паспорт сервисного аккаунта целиком.
3. Сохранить. Раз в минуту бот забирает новые ответы и публикует заявки.
   Следить: вкладка «Журнал» → записи «Опрос Google-формы».

## Часть 4. Вариант B — вебхук через Google Apps Script

### 4.1. Вебхуки Discord

В каждом из трёх каналов: Настройки канала → **Интеграции → Вебхуки →
Новый вебхук** → скопировать URL (`https://discord.com/api/webhooks/XXXX/YYYY`).

### 4.2. Скрипт в форме

Форма → ⋮ → **Редактор скриптов** → вставьте код, заменив три URL:

```javascript
// === ВАШИ ВЕБХУКИ ===
const HOOK_ROLES    = "https://discord.com/api/webhooks/XXXX/roles";
const HOOK_VACATION = "https://discord.com/api/webhooks/XXXX/vacation";
const HOOK_SHDS     = "https://discord.com/api/webhooks/XXXX/shds";

function onFormSubmit(e) {
  const a = {};
  for (const item of e.response.getItemResponses()) {
    a[item.getItem().getTitle().trim()] = String(item.getResponse()).trim();
  }

  const name   = a["Имя пользователя"] || "";
  const did    = (a["Discord ID"] || "").replace(/\D/g, "");
  const type   = (a["Тип заявки"] || "").toLowerCase();
  const unit   = a["Подразделение"] || "Танковая рота";
  const rank   = a["Звание"] || "";
  const steam  = a["Steam ID"] || "";
  const give   = a["Роль (выдать)"] || "";
  const remove = a["Роль (снять)"] || "";
  const exam   = a["Экзамен"] || "";
  const grade  = a["Оценка"] || "";
  const examiner = a["Экзаменатор"] || "";
  const dates  = a["Даты отпуска"] || "";
  const reason = a["Причина"] || "";

  let hook = "", content = "";

  if (type.indexOf("отпуск") !== -1) {
    hook = HOOK_VACATION;
    content = "Тип заявки: " + (type.indexOf("снять") !== -1 ? "Снятие отпуска" : "Отпуск") + "\n" +
              "Имя пользователя: " + name + "\n" +
              (did ? "Discord ID: " + did + "\n" : "") +
              "Подразделение: " + unit + "\n" +
              (dates ? "Даты отпуска: " + dates + "\n" : "") +
              (reason ? "Причина: " + reason : "");
  } else if (type.indexOf("экзамен") !== -1) {
    hook = HOOK_SHDS;
    content = "Подразделение: " + unit + "\n" +
              "Редакция ШДС: Получение подтверждения об экзаменации\n" +
              "Имя пользователя: " + name + "\n" +
              "Сданные экзамены: " + exam + "\n" +
              (did ? "Discord ID: " + did + "\n" : "") +
              (grade ? "Оценка: " + grade + "\n" : "") +
              (examiner ? "Экзаменатор: " + examiner + "\n" : "") +
              (reason ? "Причина: " + reason : "");
  } else if (type.indexOf("роль") !== -1 || type.indexOf("роли") !== -1) {
    hook = HOOK_ROLES;
    const parts = [];
    if (give) parts.push("Выдать " + give);
    if (remove) parts.push("Снять " + remove);
    content = (did ? "<@" + did + ">" : name) + "\n" +
              "Заявка из Google-формы: " + name + "\n" +
              parts.join(", ");
  } else if (type.indexOf("шдс") !== -1) {
    hook = HOOK_SHDS;
    content = "Подразделение: " + unit + "\n" +
              "Редакция ШДС: Добавление в ШДС\n" +
              "Имя пользователя: " + name + "\n" +
              "Звание: " + rank + "\n" +
              "Steam ID: " + steam + "\n" +
              "Discord ID: " + did + "\n" +
              (give ? "Роли выдать: " + give + "\n" : "") +
              (remove ? "Роли снять: " + remove + "\n" : "") +
              (reason ? "Причина: " + reason : "");
  } else if (type.indexOf("запас") !== -1) {
    hook = HOOK_SHDS;
    const action = (type.indexOf("вернуться") !== -1) ? "Возврат из запаса" : "Уход в запас";
    content = "Подразделение: " + unit + "\n" +
              "Редакция ШДС: " + action + "\n" +
              "Имя пользователя: " + name + "\n" +
              "Звание: " + rank + "\n" +
              "Steam ID: " + steam + "\n" +
              "Discord ID: " + did + "\n" +
              (reason ? "Причина: " + reason : "");
  } else {
    return;
  }

  UrlFetchApp.fetch(hook, {
    method: "post",
    contentType: "application/json",
    payload: JSON.stringify({ username: "Google-форма АТК", content: content })
  });
}
```

Сохраните → **Триггеры** (часы слева) → Добавить триггер → функция
`onFormSubmit`, событие **«При отправке формы»** → сохранить → дать разрешения.

### 4.3. Автозаполнение списков в форме (бойцы, роли, экзамены)

Чтобы «Имя пользователя» и «Роль» были выпадающими списками с актуальными
данными, добавьте в тот же редактор скриптов:

```javascript
// Раз в день обновляет списки в форме из таблицы ШДС и с сервера Discord
function refreshChoices() {
  const SS_ID = "1FkC6pdThOnQ_chrKy90bIsM2xEr6qeazhN_OCsSO-s0";
  const ss = SpreadsheetApp.openById(SS_ID);
  const form = FormApp.getActiveForm();

  // --- Имена бойцов из ШДС (колонка C — Танковая рота, D — Артдивизион) ---
  const names = [];
  [["Танковая рота", 3, 10, 56], ["Артиллерийский дивизион", 4, 12, 41]]
    .forEach(([title, col, top, bottom]) => {
      const sh = ss.getSheetByName(title);
      if (!sh) return;
      for (let r = top; r <= bottom; r++) {
        const v = String(sh.getRange(r, col).getValue() || "").trim();
        if (v && v.toLowerCase() !== "вакант") names.push(v);
      }
    });

  // --- Роли с сервера (через панель; нужен CRON_SECRET и guild_id) ---
  let roles = [];
  try {
    const res = UrlFetchApp.fetch("https://atk-red.site/api/roles?key=ВАШ_CRON_SECRET");
    roles = JSON.parse(res.getContentText()).roles || [];
  } catch (err) { /* панель недоступна — список ролей не обновляем */ }

  for (const item of form.getItems()) {
    const t = item.getTitle().trim();
    if (t === "Имя пользователя" && names.length)
      item.asListItem().setChoices(names.map(n => FormApp.createChoice(n)));
    if ((t === "Роль (выдать)" || t === "Роль (снять)") && roles.length)
      item.asListItem().setChoices(roles.map(n => FormApp.createChoice(n)));
  }
}
```

Триггер: `refreshChoices` → «По времени» → «Ежедневно».
Для `/api/roles` в панели должен быть заполнен `guild_id` (ID сервера).
Список экзаменов и оценок заполните вручную один раз (меняются редко).

## Часть 5. Локальное тестирование в Docker (до выкладки на сайт)

### 5.1. Подготовка

1. Установите Docker Desktop. В `.env` должны быть:
   ```
   POSTGRES_PASSWORD=ваш_пароль
   DATABASE_URL=postgresql://postgres:ваш_пароль@127.0.0.1:5432/app_db
   JWT_SECRET=случайная_строка_32+_символа
   CRON_SECRET=другая_случайная_строка
   DISCORD_BOT_TOKEN=токен_бота
   TZ=Europe/Moscow
   ```
2. **Discord Developer Portal** → ваш бот → Bot → включите Privileged
   Gateway Intents: **SERVER MEMBERS**, **MESSAGE CONTENT**.
   Роль бота на сервере должна стоять в иерархии **выше** всех ролей,
   которые он выдаёт/снимает.
3. **Тестовый полигон:** создайте на Discord-сервере три тестовых канала
   (шдс-тест, отпуск-тест, роли-тест). Сделайте **копию** таблицы ШДС
   (Файл → Создать копию) и тестируйте на ней — боевой документ не пострадает.
   Дайте сервисному аккаунту права Редактора на копию.

### 5.2. Запуск

```bash
docker compose up -d --build     # БД + миграции + приложение
# или для разработки без Docker (нужен запущенный postgres):
npm run dev
```

Панель: http://localhost:3000. В консоли должно появиться
`🤖 Бот-слушатель АТК ... запущен`. Первый вход: логин/пароль из
`scripts/seed-admin.mjs` (`node scripts/seed-admin.mjs`).

### 5.3. Настройка панели (локально)

Заполните в Настройках:
- каналы — ID ваших **тестовых** каналов;
- `gsheet_spreadsheet_id` — ID **копии** таблицы;
- `gsheet_service_account` — JSON-паспорт;
- `moderator_role_id`, `leave_role_id`, `reserve_role_id`, `reserve_sheet_name`;
- включите «Опрос Google-формы», лист `Ответы на форму 1`.

| Тест | Как проверить | Ожидание |

Добавить в ШДС + роли** | Отправьте форму: тип «Добавить в ШДС», подразделение «Танковая рота», имя, звание «Рядовой», Steam ID, Discord ID → 🟢 | В копии таблицы имя появилось в первой «Вакант»-строке блока; в Discord **автоматически** выдались роли: ТР + корпус + категория «Звания» + «Рядовой», снялись «Новобранец»/«Друг АТК»; под заявкой ветка с итогом |
| **2а. Отпуск** | Тип «Отпуск», даты «с ДД.ММ.ГГГГ по ДД.ММ.ГГГГ» → 🟢 | Роль «Отпуск» выдана; в панели боец помечен «В отпуске»; бойцу пришло ЛС |

| **4. Экзамен** | Тип «Сдать экзамен», подразделение, имя, экзамен из шапки ШДС, оценка, экзаменатор «Иванов И.И.» → 🟢 | Ячейка экзамена зелёная, внутри оценка; в примечании ячейки «Экзаменатор: Иванов И.И. + дата». Для КМБТ оценка не пишется |
| **5а. Уйти в запас** | Тип «Уйти в запас» → 🟢 | Строка целиком (с зелёными экзаменами!) появилась на листе «Запас»; в подразделении — «Вакант»; роли сняты, выдан «Запас» |
| **5б. Вернуться из запаса** | Тип «Вернуться из запаса» → 🟢 | Строка с экзаменами вернулась в НИЖНЮЮ свободную строку блока прежней должности; «Запас» снят, прежние роли возвращены |
| **6. Отказ** | Любая заявка → ❌ | Префикс [ОТКАЗАНО], ветка с именем модератора, ничего не изменено |
| **7. Права** | Реакция от бойца без роли модератора | Реакция снимается, ветка «Недостаточно прав» |
| **8. Синк состава** | В панели задайте бойцу Discord ID и отпуск → дождитесь автосинка (30 мин) или нажмите «Синхронизация» | Discord ID и отпуск СОХРАНИЛИСЬ |

| Симптом | Причина | Решение |
|---|---|---|
| Заявки не появляются (вариант A) | опрос выключен | Настройки → «Google-форма и запас» → включить |
| «Лист не найден» | неверное имя листа | проверьте `form_response_sheet` |
| 403 от Google | нет доступа | дайте сервисному аккаунту права Редактора (п. 2.3) |
| Реакция снята, «Недостаточно прав» | реагирующий не модератор | выдайте роль `moderator_role_id` |
| «Боец не найден на листе» | имя в форме ≠ имени в ШДС | имя должно совпадать со столбцом C/D листа |
| «Столбцы экзаменов не найдены» | название экзамена в форме ≠ заголовку в ШДС | скопируйте заголовок из шапки листа |
| Роли не выдаются | роль бота ниже в иерархии | поднимите роль бота выше выдаваемых ролей |
| Бот не видит содержимое сообщений | не включён MESSAGE CONTENT intent | Developer Portal → Bot → Privileged Intents |
| Отпуск не снимается автоматически | не заполнен `leave_role_id` или даты | укажите роль «Отпуск»; дату конца в формате ДД.ММ.ГГГГ |
| Discord ID не находится при выборе из списка | у бойца нет ID в БД и в ШДС | заполните колонку Discord ID в ШДС или попросите бойца указать ID в форме |
| Данные бойца «пропадали» после синка | старый баг syncRoster | исправлено: `discordId`, `vacation`, `vacationUntil` не затираются |
