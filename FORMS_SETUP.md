# Инструкция: Google-форма заявок и запас

Эта инструкция пошагово объясняет, как подключить Google-форму, через которую
бойцы смогут подавать заявки на: выдачу/снятие роли, добавление в ШДС, отпуск,
уйти в запас / вернуться из запаса. Все заявки проходят подтверждение
модератора в Discord (реакция ✅ / ❌).

---

## 1. Создание Google-формы

1. Откройте [Google Forms](https://forms.google.com) и создайте новую форму.
2. Назовите её, например: **«Заявки АТК — роли / ШДС / отпуск / запас»**.
3. Добавьте следующие вопросы (порядок не важен, бот ищет по заголовкам):

| Вопрос | Тип | Обязательный | Пояснение |
|---|---|---|---|
| **Имя пользователя** | Текст (короткий) | ✅ | Как в ШДС / Discord |
| **Discord ID** | Текст (короткий) | ✅ | Цифровой ID (см. п. 1.1) |
| **Тип заявки** | Выпадающий список | ✅ | Варианты — см. п. 1.2 |
| **Подразделение** | Выпадающий список | ✅ | «Танковая рота», «Артиллерийский дивизион» |
| **Звание** | Текст (короткий) | ❌ | Для ШДС / запаса |
| **Steam ID** | Текст (короткий) | ❌ | Для ШДС |
| **Роль** | Выпадающий список (с поиском) | ❌ | Для «Выдать/Снять роль» |
| **Даты отпуска** | Текст (короткий) | ❌ | Например: «с 10.11 по 20.11» |
| **Причина** | Текст (абзац) | ❌ | Любой комментарий |

### 1.1 Как узнать Discord ID

- В Discord: Настройки → Расширенные → **Режим разработчика** (вкл).
- ПКМ по своему нику → «Копировать ID пользователя».

### 1.2 Варианты для «Тип заявки»

Добавьте в выпадающий список ровно эти 6 вариантов (регистр не важен):

```
Выдать роль
Снять роль
Добавить в ШДС
Отпуск
Уйти в запас
Вернуться из запаса
```

### 1.3 Выпадающий список «Роль» с поиском

Google Forms автоматически даёт поле поиска, когда в списке больше ~10
пунктов. Список ролей можно вставить вручную (см. п. 3) или обновлять через
Apps Script (см. п. 4).

---

## 2. Связь формы с Google-таблицей

1. В форме откройте вкладку **«Ответы»**.
2. Нажмите значок зелёной таблицы («Создать таблицу»).
3. Выберите **«Создать новую таблицу»** → нажмите «Создать».
4. Откроется Google-таблица. **Скопируйте её ID** из URL:
   ```
   https://docs.google.com/spreadsheets/d/СЮДА_ID_ТАБЛИЦЫ/edit
   ```
5. Переименуйте лист с ответами в `Ответы на форму 1` (или запомните своё
   название — его надо будет вписать в настройках панели).

> ⚠️ **Важно:** форма и таблица ШДС — это **разные** документы. Форма пишет
> ответы в свою таблицу, а бот ШДС работает с таблицей ШДС (где листы
> «Танковая рота» / «Артиллерийский дивизион»).

---

## 3. Доступ сервисного аккаунта к таблице формы

Бот читает ответы формы через сервисный аккаунт Google. Нужно дать ему доступ:

1. Откройте JSON-паспорт сервисного аккаунта (настройка `gsheet_service_account`
   в панели) и найдите поле `client_email` — это email вида
   `...@...iam.gserviceaccount.com`.
2. Откройте таблицу с ответами формы → «Настройки доступа» → «Поделиться».
3. Добавьте этот email с правами **Редактор**.

## 4. (Опционально) Автообновление списка ролей в форме

Если роли на сервере часто меняются, список в форме можно обновлять
автоматически через Google Apps Script:

1. Откройте форму → меню (⋮) → **Редактор скриптов**.
2. Вставьте код:

```javascript
function syncRoles() {
  const PANEL_URL = "https://atk-red.site"; // или http://IP:3000 локально
  const KEY = "ваш_CRON_SECRET";

  const res = UrlFetchApp.fetch(`${PANEL_URL}/api/roles?key=${KEY}`);
  const data = JSON.parse(res.getContentText());
  if (!data.roles) throw new Error("Роли не получены");

  const form = FormApp.getActiveForm();
  const items = form.getItems();
  let roleItem = null;
  for (const item of items) {
    if (item.getTitle() === "Роль") { roleItem = item; break; }
  }
  if (!roleItem) throw new Error("Вопрос «Роль» не найден в форме");

  const choices = data.roles.map(r => FormApp.createChoice(r));
  roleItem.asListItem().setChoices(choices);
}
```

3. Выберите функцию `syncRoles` → **Запустить** (дайте разрешения).
4. Настройте триггер: слева значок часов → добавить триггер →
   `syncRoles` / «По времени» / «Ежедневно» → любой час.

> Примечание: для работы `syncRoles` нужен эндпоинт `/api/roles`, который
> возвращает список ролей. Если его нет — используйте ручной список из п. 1.3.

## 5. Настройка панели

Откройте панель → **Настройки** → секция **«Google-форма и запас»**:

| Настройка | Что вписать |
|---|---|
| **Опрос Google-формы** | Включите (переключатель) |
| **Лист с ответами формы** | Название листа из п. 2 (по умолч. `Ответы на форму 1`) |
| **ID роли «Запас»** | Цифровой ID роли «Запас» на сервере Discord |
| **Название листа «Запас»** | По умолчанию `Запас` (создастся автоматически) |

Также убедитесь, что заполнены каналы в секции **«Бот заявок и Google Таблица»**:
- `ID канала заявок ШДС` — куда пойдут заявки на ШДС и запас
- `ID канала заявок на отпуск` — куда пойдут заявки на отпуск
- `ID канала запросов ролей` — куда пойдут заявки на роли

Нажмите **«Сохранить всё»**.

---

## 6. Как это работает (для бойца)

1. Боец заполняет форму и отправляет.
2. В течение минуты бот забирает ответ и публикует заявку в нужный канал
   Discord — в том же формате, как если бы её написали вручную.
3. Модератор (или упомянутый экзаменатор) ставит под заявкой реакцию:
   - **✅ / 🟢 / :ATK:** — одобрить
   - **❌** — отказать
4. Бот выполняет заявку (выдаёт/снимает роль, вносит в таблицу ШДС,
   переводит в запас) и создаёт ветку с итогом.

---

## 7. Как это работает (для запаса)

**Уйти в запас:**
- Строка бойца копируется на лист «Запас» (колонки: имя, звание,
  подразделение, Steam ID, Discord ID, должность, дата).
- На листе подразделения строка затёрта шаблоном «Вакант».
- В Discord: сняты все роли клана, выдана роль «Запас».

**Вернуться из запаса:**
- Бот находит бойца на листе «Запас» и возвращает его на лист
  подразделения (первая свободная «Вакант»-строка).
- Строка на листе «Запас» очищается.
- В Discord: роль «Запас» снята, сохранённые роли восстановлены.

## 8. Локальное тестирование (без сервера)

1. Убедитесь, что `.env` содержит `DATABASE_URL`, `JWT_SECRET`,
   `DISCORD_BOT_TOKEN`, `gsheet_spreadsheet_id`, `gsheet_service_account`.
2. Запустите `npm run dev`.
3. Заполните форму тестовой заявкой.
4. Откройте панель → Настройки → «Google-форма и запас» → включите опрос.
5. Подождите до минуты — заявка появится в канале Discord.
6. Проверьте вкладку «Журнал» → «Сайт» — там будет запись
   «Опрос Google-формы».

---

## 9. Устранение проблем

| Симптом | Причина | Решение |
|---|---|---|
| Заявки не появляются | Опрос выключен | Включите в настройках панели |
| Ошибка «Лист не найден» | Неверное имя листа | Проверьте `form_response_sheet` |
| Ошибка «client_email не найден» | Нет доступа к таблице | Дайте доступ сервисному аккаунту (п. 3) |
| Заявка без реакций | Не тот канал | Проверьте ID каналов в настройках |
| Запас не работает | Нет роли «Запас» | Впишите `reserve_role_id` в настройках |
4. То же самое повторите для таблицы ШДС, если ещё не сделали.
