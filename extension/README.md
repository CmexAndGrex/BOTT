# RED OPS Cookie Sync v4 — zero-config

Расширение без настройки: адрес панели и ключ синхронизации вшиваются в архив
автоматически при его скачивании из панели RED OPS. Ничего вводить не нужно.

## Установка — три шага

1. Скачайте архив из панели (Настройки → Автосинхронизация cookie).
   Внутри него уже ваш текущий адрес сервера и ключ.
2. Распакуйте архив в отдельную папку.
3. Откройте `chrome://extensions`, включите «Режим разработчика» и нажмите
   «Загрузить распакованное расширение» — выберите папку.

Готово. Расширение сразу в рабочем состоянии и начнёт передачу по расписанию.

## Как это работает

- Cookie читаются через системное разрешение браузера `chrome.cookies` — только
  домен rs-red.com.
- Отправка идёт прямым запросом из service worker на вшитый адрес `/api/cookie`.
  Домен панели уже присутствует в host_permissions архива, поэтому CORS-политика
  браузера к расширению не применяется.
- Панель «пробуждается» автоматически: перед отправкой расширение до 8 раз
  проверяет health-запросом, что отвечает именно API (фирменный JSON), а не
  прокси-заставка.
- При сбое — автоматический повтор через минуту.

## Когда отправляются cookie

- после входа/изменения cookie на rs-red.com;
- раз в 10 минут;
- при запуске браузера;
- вручную кнопкой «Отправить сейчас» в попапе.

## Если панель переехала (новый адрес)

Архив персонален: в нём зашит адрес панели на момент скачивания. Когда адрес
панели меняется (перезапуск превью, перенос на другой хостинг) — удалите старое
расширение, скачайте архив заново из актуальной панели и загрузите вместо старого.
На сервере с постоянным доменом эта процедура нужна один раз.

## Безопасность

- Расширение видит только cookie rs-red.com и имеет доступ только к вшитому домену панели.
- Ключ синхронизации хранится внутри архива и никуда, кроме вашей панели, не уходит.
- Ключ можно перевыпустить в панели — старый клиент перестанет приниматься сервером.
