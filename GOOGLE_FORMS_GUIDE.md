# 📋 Инструкция: Google Формы для увольнения из ШДС (ATK RED)

Пошаговое руководство для администраторов: как настроить Google Форму,
которая при отправке автоматически уведомляет бота ATK RED.

---

## Шаг 1. Создание Google Формы

1. Откройте [forms.google.com](https://forms.google.com) и нажмите **«Создать пустую форму»**.
2. Задайте название, например: **«Заявка на увольнение из ШДС — ATK RED»**.
3. Добавьте **обязательные** поля (переключатель «Обязательный вопрос» — ВКЛ):

   | № | Поле                        | Тип вопроса          | Обязательно |
   |---|-----------------------------|----------------------|-------------|
   | 1 | Ник в игре                  | Короткий ответ       | ✅          |
   | 2 | Discord ID                  | Короткий ответ       | ✅          |
   | 3 | Подразделение               | Список (выпадающий)  | ✅          |
   | 4 | Причина увольнения          | Абзац                | ✅          |
   | 5 | Дата увольнения             | Дата                 | ✅          |

4. В **«Настройки» → «Презентация»** включите «Показывать ссылку для отправки еще одного ответа» (по желанию).
5. Нажмите **«Отправить»** → иконка ссылки 🔗 → скопируйте ссылку на форму (она понадобится бойцам).

> ⚠️ Discord ID бойца должен быть числовым (например `1185432109876543210`) —
> именно по нему бот найдёт пользователя.

---

## Шаг 2. Google Apps Script — готовый код

1. В редакторе формы нажмите **⋮ (три точки) → «Редактор скриптов»**.
2. Удалите весь шаблонный код и вставьте следующий скрипт:

```javascript
/**
 * ATK RED — отправка заявки на увольнение из ШДС в бота.
 * Срабатывает автоматически при каждой отправке формы.
 */

// 👇 ВСТАВЬТЕ СЮДА публичную ссылку на ваш сервер (ngrok или боевой адрес)
const WEBHOOK_URL = "https://ВАША-ССЫЛКА-СЮДА.ngrok-free.app/api/form-webhook";

function onFormSubmit(e) {
  var answers = e.response.getItemResponses();
  var payload = {};

  for (var i = 0; i < answers.length; i++) {
    var item = answers[i].getItem();
    payload[item.getTitle()] = answers[i].getResponse();
  }

  // Единый формат для бота
  var body = {
    type: "shds_dismissal",
    nickname: payload["Ник в игре"] || "",
    discordId: payload["Discord ID"] || "",
    subdivision: payload["Подразделение"] || "",
    reason: payload["Причина увольнения"] || "",
    date: String(payload["Дата увольнения"] || ""),
    submittedAt: new Date().toISOString(),
    raw: payload
  };

  var options = {
    method: "post",
    contentType: "application/json",
    payload: JSON.stringify(body)
  };

  try {
    UrlFetchApp.fetch(WEBHOOK_URL, options);
    Logger.log("✅ Заявка отправлена: " + JSON.stringify(body));
  } catch (err) {
    Logger.log("❌ Ошибка отправки: " + err);
    // Письмо администратору, если сервер недоступен
    MailApp.sendEmail(
      Session.getActiveUser().getEmail(),
      "[ATK RED] Ошибка вебхука формы увольнения",
      "Не удалось отправить заявку в бота.\n\nОшибка: " + err +
      "\n\nДанные заявки:\n" + JSON.stringify(body, null, 2)
    );
  }
}
```

3. Замените `https://ВАША-ССЫЛКА-СЮДА.ngrok-free.app` на ваш реальный адрес
   (локальный тест через ngrok — см. Шаг 4, боевой сервер — адрес панели бота).
4. Нажмите **💾 «Сохранить»** (Ctrl+S).

---

## Шаг 3. Включение триггера onFormSubmit

1. В редакторе скриптов слева нажмите на иконку **⏰ будильника («Триггеры»)**.
2. Нажмите **«+ Добавить триггер»** (правый нижний угол).
3. Заполните:
   - **Выберите функцию:** `onFormSubmit`
   - **Выберите источник события:** `Из формы`
   - **Выберите тип события:** `При отправке формы`
   - **Уведомления об ошибках:** «Немедленно» (рекомендуется)
4. Нажмите **«Сохранить»**. Google попросит разрешения — войдите в аккаунт,
   нажмите **«Дополнительные настройки» → «Перейти на страницу … (небезопасно)»**
   и разрешите доступ (скрипт ваш, это нормально).

Готово — теперь каждая отправка формы уходит в бота.

## Шаг 4. Локальное тестирование через ngrok

Бот работает на вашем компьютере (порт **3000**), а Google должен достучаться
до него из интернета. Для этого используется туннель ngrok:

1. **Установите ngrok** (если ещё нет):
   ```bash
   npm install -g ngrok
   ```
   или скачайте с [ngrok.com/download](https://ngrok.com/download) и зарегистрируйте
   бесплатный аккаунт.

2. **Запустите бота** (в корне проекта `E:\ATK\BOT`):
   ```bash
   npm run dev
   ```
   Дождитесь сообщения, что сервер поднялся на `http://localhost:3000`.

3. **В отдельном окне терминала запустите туннель**:
   ```bash
   ngrok http 3000
   ```

4. ngrok покажет строку вида:
   ```
   Forwarding  https://abc123xyz.ngrok-free.app -> http://localhost:3000
   ```
   Скопируйте **https-ссылку** (`Forwarding`).

5. **Вставьте её в скрипт** (Шаг 2), добавив путь вебхука:
   ```javascript
   const WEBHOOK_URL = "https://abc123xyz.ngrok-free.app/api/form-webhook";
   ```
   Сохраните скрипт (⏰ будильник-триггер пересоздавать не нужно).

6. **Проверьте работу**: откройте ссылку на форму (Шаг 1), заполните её тестовыми
   данными и отправьте. Затем:
   - посмотрите журнал панели бота / терминал `npm run dev` — должен появиться запрос;
   - проверьте Discord-канал ШДС — бот опубликует заявку;
   - при ошибке зайдите в редактор скриптов → **«Журнал выполнения»** и прочитайте лог.

> 💡 **Важно:** бесплатная ссылка ngrok меняется при каждом перезапуске.
> Для постоянной работы пропишите в скрипте адрес боевого сервера панели.
